# 2006 BMW 325xi — Interactive 3D Viewer

GitHub Pages site for a photo-informed concept model of a 2006 BMW 325xi (E90).

## Publish

1. Create a **public** GitHub repository named `bmw-325xi-3d`.
2. Upload the contents of this folder to the **root** of the repository, retaining the `models/` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
5. After deployment completes, open `https://YOUR-USERNAME.github.io/bmw-325xi-3d/`.

The viewer uses Google's `<model-viewer>` web component loaded from a CDN. Internet access is required. The model is a simplified concept reconstruction rather than a high-fidelity scan.
